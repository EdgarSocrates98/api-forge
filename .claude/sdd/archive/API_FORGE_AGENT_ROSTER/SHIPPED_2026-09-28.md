## Summary

The 52 API Forge coordinators, most of them stubs, are now 25 English agents. Each has a nine-section contract, a declared access level (`read-only`, `state-writer` or `writer`) and real `apiforge` commands that it alone owns. All 25 come from one source, `agents/*.md`, rendered deterministically for Claude Code, Devin and Codex, and the release gate enforces them through render drift, contract lint (commands must exist and playbooks must be coherent), referential integrity and `agents audit` (25/25 keep, up from 8/52). The 33 retired names still resolve, with a deprecation warning. Routing quality improved on an independent 80-case holdout written by two other models.

## Lessons Learned

### Process

- An independent critic after the build found problems that the self-authored gates missed: fake command ownership, read-only agents that write state, and playbooks with verbs that do not exist. Run the critic before the verify evidence is written, not after.
- Commit golden cases before rewriting content (pre-registration). It made the leakage analysis possible, but pre-registration does not stop the same author from leaking vocabulary. An independent holdout needs another author from the start.
- The DEFINE miscounted the aliases (27 vs 33). Compute counts from data (`52 − kept`) instead of writing them by hand.

### Technical

- A mirror gate cannot stay byte-identical once hosts need different projections. Compare against `render(source, host)` and keep one code path for both write and check.
- Declared ownership must be validated against the real CLI tree (Typer walk). Otherwise uniqueness audits reward invented commands.
- Permissions need three levels. Agents that persist state through the product's own commands are neither read-only nor file writers.
- A lexical proxy router is good at detecting description collisions and weak at predicting real routing (holdout top-1 0.46). Treat it as a regression floor, not as a quality score.

### Communication

- The owner stating "host-neutral" early shaped the renderer design. Asking about the language (English) prevented a mixed-language roster.

### Tools & Libraries

- Codex custom-agent TOML (`name`, `description`, `developer_instructions`, `sandbox_mode`) from the official docs mapped cleanly. Claude Code reloaded the rendered agents live, which confirmed the projection.
- Haiku as a holdout author returned summaries instead of payloads, so file-writing instructions had to be explicit. Sonnet followed them on the first try but ignored the per-agent coverage rule (20 of 25 agents).
