## Lessons Learned

### Technical

- A second loader for trusted data is a second trust boundary; delete it rather than harden it.
- "Share of a budget" must name its population: per instance silently multiplies.
- A counter that some calls bypass is telemetry, not a budget.
- A boolean "seen any measurement" cannot represent coverage.
- Early stop must depend on receipts, never on text that mentions them.

### Process

- High-risk SDD changes need the `critical` profile and a measured benchmark phase — the gate caught it.
