## Summary

Waves 0 and 1 of the API Forge economy program. `apiforge context capsule` returns the minimum evidence for one operation as `ctx://sha256/…` references selected from the persisted case graph: operation, referenced schemas, handler slice, code models carried as `parity`/`delta`, findings and tests. The selection stays under a byte budget, and the references are hash-verified when expanded. A new attribution ledger (`economy stats|explain`) records which source spent the bytes and why. On a 12-case benchmark, the capsule kept evidence recall equal to baseline in 12/12 cases and cut median bytes by 47.7%. That figure charges the full expansion of every ref. Tokens were never inferred.

## Lessons Learned

### Process

- Running the full suite only once at the end, with targeted tests per task, kept iteration fast. The only full-suite surprise was the release gate's `docs/contracts/<Name>-v1.md` requirement. Next time, read `scripts/check_release.py` during Design and add its obligations to the file manifest.
- The Design's baseline decision ("what an agent reads today") mattered more than any code choice. It is what made the reduction claim honest.

### Technical

- The case graph maps one route fact per `(method, path)`. Selection also needs a direct `code.route` fact match, otherwise duplicate handlers are silently dropped.
- Absolute paths inside a payload break determinism across machines. Anything that gets hashed must be root-relative.
- Brace matching for Java/Go must strip string literals first: `@GetMapping("/{id}")` counts as a block otherwise.
- A partial result has to reserve room for its own refusal, or the budget ceiling is exceeded exactly when it matters.
- Capsule selection exposed a real contract↔code drift in an existing fixture (`/v1` prefix). `unresolved: code-route-missing:*` turns that into evidence instead of a silent gap.

### Communication

- Resolving DEFINE Q1 (partial vs refusal) and Q2 (ref identity) in DESIGN ADRs prevented rework during build.
- The bare `/design` command collided with the Artifact "Design" type. Suggest the fully qualified `/agentspec:workflow:*` commands.

### Tools & Libraries

- `tokensave`: fast for mapping existing contracts, but its grep hook blocks lookups in files it has not indexed yet. Use `TOKENSAVE_DISABLE_GREP_HOOK=1` for new files.
- Windows specifics: Python `write_text` emits CRLF and typer stdout is CRLF. Normalize before hashing evidence. pytest needs `--basetemp` outside the repo.
