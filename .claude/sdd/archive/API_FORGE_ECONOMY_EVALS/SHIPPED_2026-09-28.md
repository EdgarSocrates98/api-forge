## Summary

The three economy profiles are now measured on the same sixteen canonical
contract changes with quality, evidence, cost, context and latency kept
apart. Economy is cheapest (2.56 calls vs 3.00 balanced and 3.44 deep) at the
same quality (1.0) and zero safety violations. Future economy changes ship
through `evals gate`, stored runs can be replayed under a new policy without
providers, `economy roi` shows whether extra agents change outcomes, runs
report their information gain, and routing can make quality a floor with cost
as the optimization.

## Lessons Learned

### Process

- A matrix with a safety axis finds catalog gaps that per-feature tests never exercise.

### Technical

- Shared request/response schemas make "relaxing required" breaking; ground truth must consider both directions.
- Keep replay inputs as portable bundles; runtime state is gitignored.

### Communication

- Report savings next to quality, never instead of it.
