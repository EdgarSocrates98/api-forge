## Lessons Learned

- A relative gate certifies "not worse", never "good"; pair it with an absolute floor.
- A denominator must be defined by rule, not by whatever rows exist.
- A counter keyed by root is not a counter of a run.
- An oracle that re-implements the logic it guards cannot detect that logic's regression; prove it with a mutation test.
- Caller-supplied paths are data too once agents and MCP hosts pass them.
