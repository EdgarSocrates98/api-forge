## Summary

The last sections of the economy program: verification plans that pick the
ladder level from risk and select only impacted tests, deterministic query
expansion with ranked progressive retrieval, one-hop `evidence://` refs, an
economy doctor, provider descriptors with evidence-gated tiering, a stable
hashed prompt prefix carried on every runtime request, and locality-first
workspaces. Everything is read-only and offline.

## Lessons Learned

### Process

- Grouping the long tail of a program into one wave works when each part is a small, separately gated verb.

### Technical

- "Nothing impacted" must escalate, not skip — a selection of zero tests is a question, not an answer.
- Helpers named `test_*` inside `src/` are collected by pytest when imported into test modules.

### Communication

- Tiering reasons must name the evidence (or its absence) every time.
