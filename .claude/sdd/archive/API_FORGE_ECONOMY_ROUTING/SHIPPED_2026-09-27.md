## Summary

Wave 3 of the economy program adds the Economy Plane to the agentic runtime.

**Profiles and risk.** `economy`, `balanced` and `deep` are resolved from the flag, then the project manifest, then the policy default. A profile is a preference and the risk floor is an invariant, so risk can raise the effective profile but never lower it.

**Plan trims.** Trims remove only optional capacity: parallel specialists, fallbacks and challengers.

**Supervisor.** Calls are capped at min(policy, TaskSpec, envelope), with a verification reserve held back. Execution follows an escalation ladder:
- L0: stop on deterministic proof.
- L2: primary plus the roles risk requires.
- L3: an extra review, triggered by low confidence, unresolved items or conflict.
- L4: debate, only within the profile ceiling unless risk forces it.
- L5: human gate.

Budget exhaustion and ceilings are explicit and cataloged, never silent downgrades.

**Risk-adaptive SDD.** Changes are classified deterministically and mapped to a minimum SDD profile, and `sdd check` refuses profiles below it.

**Result.** On a 15-case corpus, economy removed all optional fanout (5 → 0) and cut invocations 6 → 2 on low-risk tasks, without dropping a single risk-required role.

## Lessons Learned

### Process

- Probing the real behavior (risk × profile matrix) before writing tests and ground truth avoided wrong expectations. For example, size S still classifies as `moderate`, and irreversible tasks are review-blocked before routing.
- Dogfooding `sdd classify` on this very feature exposed a classifier gap (versioned contracts counted as `low`) that the unit cases missed.

### Technical

- The supervisor ran every role concurrently. A safe ladder needs staging that keeps risk-required roles in the first stage and gates only optional escalation.
- `ControlPlane.start` consumes a call, so caps must be applied before steps start, not only in `run_bounded`.
- Resume must never re-derive plan trims. The control run is the source of truth for already-planned steps.
- The release gate recognizes codes only as standalone quoted literals, so codes need module constants when they are embedded in messages.

### Communication

- Declaring "default `balanced` changes unprofiled runs" in DEFINE (AT-015) made the one behavior-changing test update an expected consequence, not a surprise.

### Tools & Libraries

- Windows: a long pytest `--basetemp` breaks git-worktree tests through path-length limits. Use a short out-of-repo path (`E:/afpt`).
- Scripted, assert-once string patches were more reliable than long shell heredocs in this environment.
