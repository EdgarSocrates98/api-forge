## Summary

Multi-agent runs no longer ship the parent context to every agent. Economy
runs build one capsule for the TaskSpec target and give each role only its
class of evidence (specialist focused, reviewer evidence plus delta, critic
decision plus evidence, referee disagreements only) under a per-role share of
the envelope; expertise packs load only when a declared trigger names them;
debates exchange structured position deltas and the referee reads a compact
packet; challengers run in a bounded, deterministic shadow that never touches
the result; and `agents audit` shows which agents own nothing unique.

## Lessons Learned

### Process

- Put statistical gates on enough samples up front; 1000 ids was too few for ±2 pp.

### Technical

- Shadow candidates must come from the plan before economy trims, otherwise the cheapest profile never learns.
- Codes inside f-strings evade source-scanning gates; keep AF codes as literals or constants.

### Communication

- Report audit verdicts as evidence gaps: 44/52 merge candidates means the catalog does not declare what makes those agents unique.

## Known Limitations

- Savings materialize only when a host honors `context_refs`/`expertise`.
- Reviewer ROI / information gain learning deferred to Wave 6.
- The audit relies on declared frontmatter; executors are generic, so `unique_validator` is rarely true.
