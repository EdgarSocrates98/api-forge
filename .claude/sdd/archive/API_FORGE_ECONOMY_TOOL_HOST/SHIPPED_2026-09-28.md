six-gateway MCP surface that still reaches all 90 tools, a measured cost for
each surface, and declared per-host projections with a verb-first map.

## Lessons Learned

### Process

- Gates set before measurement are guesses; revise them in the open with the measured number and the reason.

### Technical

- Lossless compaction of JSON is worth ~37%; the big wins are slicing (≈90–95%) and not publishing schemas (≈94%).
- Word boundaries do not exist after `:`; `panic:` needs its own alternative.

### Communication

- Declare host behavior (deferred tool schemas) next to the measured surface so nobody over-claims savings.
