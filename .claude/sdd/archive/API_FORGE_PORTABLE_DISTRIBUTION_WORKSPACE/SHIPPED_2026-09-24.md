## Summary

API Forge now has a package-owned, portable and host-agnostic first wave. Users
can install it into a virtual environment or another writable prefix, run the
core inspection and context commands without a host, network daemon or provider
SDK, and connect independent repositories through bounded workspace manifests and
evidence-labelled graph/context projections. Host assets and MCP remain optional,
provenance-aware and plan-only where mutation would be involved. The feature was
verified, documented, committed and archived with its deferred roadmap intact.

## Lessons Learned

### Process

- Verify the repository's actual SDD document layout before invoking a generic
  phase checker; the AgentSpec linter accepted the flat documents while the
  native checker expected feature directories.
- Keep a release-gate pass in the build loop: registering contract docs and
  emitting exact refusal literals caught issues that ordinary tests did not.

### Technical

- Package resources plus SHA-256 provenance allow host adapters and knowledge
  assets to remain installed-package concerns rather than copied repository state.
- Stable repository IDs must include the canonical root, not only the directory
  name, because independent sibling repositories can share names.
- Preserving the serialized `schema` key protected contract compatibility, but a
  future alias migration should remove the Pydantic shadow warnings deliberately.

### Communication

- The explicit list of deferred features prevented scope expansion into
  autonomous orchestration, complete inference, remote updates and host parity.
- Calling out restricted machines, missing admin access and blocked networks as
  first-class requirements produced a clearer `doctor` contract and safer docs.

### Tools & Libraries

- `importlib.resources` made asset loading independent of the current checkout.
- `pytest` temporary-directory isolation was necessary on Windows to prevent
  global Temp permissions and repository ancestry from changing test semantics.
- Ruff, mypy, the release gate and AgentSpec linter provided complementary
  evidence: style, types, repository contract parity and SDD structure.
