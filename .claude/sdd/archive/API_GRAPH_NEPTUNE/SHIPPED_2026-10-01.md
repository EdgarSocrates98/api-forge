## Summary

API Forge gained a vendor-neutral graph-database specialist. One new agent
(`api-graph-data-architect`) and skill (`api-forge-graph`) own graph stores; vendor knowledge
lives in `knowledge/` packs (`graph-databases`, `neptune` v2, `neo4j`). Code now extracts
Gremlin/openCypher/SPARQL call sites for Neptune and Neo4j across Python, Java, Go and
TypeScript into a typed `GraphAccessIR`, judges them with 16 new `AF-GDB-*` rules plus
`AF-DATA-013`, parses seven explain/profile formats into `GraphPlanIR`, fetches plans through a
read-only allowlisted collector, and exports the system graph as Neptune Gremlin CSV or RDF
N-Triples. Plans and cardinality stop being blind spots wherever a plan dump exists; where
none exists they stay `unresolved`.

## Lessons Learned

### Process

- Holdout cases written after calibration found a real bug (Gremlin chain inside a Java comment)
  that the 79 in-distribution cases missed. Keep a holdout slice in every golden corpus and
  never tune against it.
- A single global recall threshold hid a regressed rule; gate every rule × language row, and
  write the regression test (AT-016) before trusting the gate.
- Delegating only independent prose to a subagent while building code directly kept the shared
  `cli.py`/`runner.py` conflict-free; the subagent also caught a naming error (OpenCSV vs
  Gremlin CSV).

### Technical

- Check namespaces before naming codes: `AF-GRAPH-*` already belonged to the system graph;
  grepping the catalog at design time avoided a collision.
- Validate wire-level assumptions against official docs before fixing a boundary: "GET-only"
  was impossible for Neptune explain (POST); the boundary became an operation allowlist, approved
  by the owner.
- A catalog check binds one fact kind, so cross-vendor rules need a unified kind
  (`data.graph.query` + `vendor`) instead of duplicated rules.
- Reuse existing mechanisms: `knowledge/` packs already existed (data-not-prose contract), so
  vendor packs went there instead of a parallel `skill/packs/`.

### Communication

- Surfacing the four design-time corrections (C1–C4) explicitly in DESIGN kept DEFINE honest
  instead of silently drifting.
- Asking the owner on the one true constraint change (collector boundary) and deciding everything
  else autonomously kept the build moving.

### Tools & Libraries

- On Windows, `Path.write_text` writes CRLF; normalize touched files to LF (repo convention).
- `scripts/gen_pack_docs.py` regenerates every pack and exposes ~31 packs of pre-existing drift;
  revert unrelated packs after running it.
- Bash heredocs containing mixed quotes broke the tool shell; write files with the editor tool.
- Snyk could not run (MCP timeout, CLI unauthenticated); Bandit served as an interim SAST pass.
