## Summary

The field validation harness now fails closed before its first real cycle. The first `field record` seals the pre-registration in `docs/field/cycle.lock.json` and every field command refuses a mutated corpus, hypothesis, gate, task set, repo set or start date. Verifier verdicts are receipts bound to an annotation digest, so any later relabelling makes them stale instead of silently counting as verified; verifiers must be independent of the executor and humans are anonymized. The gap report exposes a provisional H1 at all times but decides H1 and recommends follow-up SDDs only when every scenario is covered inside the enforced 40-run / 4-week timebox. Inferred HTTP relations now cite both caller and callee route. The value is a trustworthy evidence chain for choosing the next roadmap theme, delivered while no field data existed to migrate.

## Lessons Learned

### Process

- Verifying every claim of an external review against file:line before scoping found an extra hole (`max_runs`/`max_weeks` declared but never enforced) and kept scope honest; do this before any brainstorm fed by a review.
- Fixing integrity while `cycle_started_at: null` and `tasks: []` let the contracts move to v2 in place with no migration; schedule integrity hardening before the first data point, not after.

### Technical

- Any rule that compares against wall-clock time creates a test time bomb when fixtures use fixed dates; add a module-level clock seam plus an autouse fixture at the same time as the rule, not after the first red CI.
- Hash the parsed model, not raw YAML bytes, when the tool itself rewrites the file (`mark_cycle_started` uses `yaml.safe_dump`); exclude the self-written key and compare it as its own component.
- Deriving staleness from a digest at read time is safer than clearing a flag on write: no future code path can forget to invalidate.
- On Windows, `Path.write_text` already emits CRLF; tests that inject line endings must normalize first.

### Communication

- Surfacing the zero-slack gate (6 scenarios × 5 = 30 = `max_runs`) during Define led the owner to raise `max_runs` to 40 before sealing — the only moment that change is legal.

### Tools & Libraries

- `apiforge sdd stamp` + `sdd check` caught mixed CRLF/LF in pytest output copied into evidence (`AF-SDD-EVIDENCE-MISMATCH`); normalize evidence to LF before hashing.
- Snyk Code refuses the repo root (`SNYK-CODE-0006`) but scans package directories; scan `src/apiforge/<pkg>` and `tests/<pkg>` directly.
