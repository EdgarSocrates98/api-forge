# AgentSpan/v1

`AgentSpan/v1` is a local, provider-neutral OTel-shaped record for agent
invocation, tool execution, handoff, decision, retrieval or checkpoint work.
It binds trace/run/task identity, status, evidence and semantic attributes;
secret-like attribute names are refused before persistence.

Canonical schema: `apiforge contract show AgentSpan/v1`.
