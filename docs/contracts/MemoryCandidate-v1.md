# MemoryCandidate/v1

`MemoryCandidate/v1` is a proposed memory item before policy promotion. It
records the immutable candidate record, proposer and reason. A candidate is not
institutional truth until `MemoryPolicy/v1` accepts it and the resulting
`MemoryOutcome/v1` is accepted.

Canonical schema: `apiforge contract show MemoryCandidate/v1`.
