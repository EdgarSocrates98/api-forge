# PlatformRuntimeReceipt/v1

`af-platform-runtime-receipt/1` records the execution of the six committed,
allowlisted probes under `tests/fixtures/platform/`. Every vertical records
the fixture, probe hash, observed time, status, checks and limitations.

The receipt proves local execution of the fixture probe. It does not prove a
remote provider, deployment, production health, performance envelope or
rollback capability.
