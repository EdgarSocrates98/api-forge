# Quickstart — API Forge (EN)

Three commands:

```bash
git clone <api-forge>
cd api-forge
./install.sh      # Windows: .\install.ps1 — wheel into the account runtime
                  # (setup.sh/setup.ps1 remains the compatibility route)
```

Then, from any project:

```bash
apiforge install --yes          # or `apiforge install` for the wizard
apiforge install status         # ledger + drift + lifecycle.state
apiforge capabilities
```
