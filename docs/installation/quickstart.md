# Quickstart — api-forge

Três comandos:

```bash
git clone <api-forge repo>
cd api-forge
./setup.sh        # Windows: .\setup.ps1
```

Depois, dentro de qualquer projeto:

```bash
cd ~/meu-projeto
apiforge install
```

Pronto. Abra seu AI host (Devin, Claude, Codex ou Copilot) — as skills do
api-forge já estão instaladas.

## Verificar

```bash
apiforge status
apiforge doctor
```
