# contract

Changes are additive and fail-closed. Public contracts keep compatibility
unless a field is explicitly versioned. New decisions and metrics preserve
`observed`, `partial`, `unresolved`, `refused` and `deferred_external` as
distinct states. A receipt proves correspondence of bytes and declared
observations; it does not prove authorship, production health or provider
freshness.
